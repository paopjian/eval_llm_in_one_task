## 💻 代码实现分析

### 核心技术实现

#### 1. Histogram方法 ✅

```python
# 200,000 bins，bin宽 1e-5
DEFAULT_NBINS = 200000
```

**特点**:
- **超高分辨率**: 200,000 bins (与Codex-sol-2相同)
- 分辨率: 0.00001
- 内存占用: O(bins) ≈ 1.6MB

#### 2. FP32精确计算（不用TF32）

```python
# 明确注释: fp32精确, 不用TF32
S = A @ Bc.T  # (m,n) fp32 精确
```

**特点**:
- ❌ **未使用TF32加速**
- ✅ 保证数值精确性
- ⚠️ 牺牲了性能换取精度

#### 3. 多卡并行 + 轮询负载均衡 ✅

```python
def assign_row_blocks(N, block, gpus):
    """行块轮询分配(上三角负载均衡)"""
    nblk = (N + block - 1) // block
    return {g: list(range(g_i, nblk, len(gpus))) for g_i, g in enumerate(gpus)}
```

**特点**:
- **轮询分配** (Round-Robin)
- 简单但有效的负载均衡
- 多卡加速比: 4.0× (理论7×，实际受限)

#### 4. 子进程模式（避免fork死锁）

```python
# 主进程只加载numpy数据
# GPU计算全部发生在 gpu_worker.py 子进程中
# 避免fork+cuda/线程死锁
```

**创新点**:
- ✅ 独立子进程，避免CUDA fork问题
- ✅ 主进程不导入torch
- ✅ 结果通过npz文件交换

#### 5. 对角块对称性优化 ✅

```python
# 对角线块利用 S=A@A^T 精确对称性:
# 全块计数 - 对角线 - 对称除2
# 只需2次 bincount, 免去上三角掩码开销
```

**特点**:
- ✅ 利用对称性优化
- ✅ 减少计算开销
- ✅ 代码简洁

#### 6. 分步实现架构 ✅

```python
step1_analyze_data.py      # 数据分析
step2_single_gpu.py        # 单卡评估(含CPU float64自检)
step3_multi_gpu.py         # 7卡并行评估
step4_extract_pairs.py     # 样本对提取
step5_plot_results.py      # 可视化
run_eval.py                # 一键入口
```

**特点**:
- ✅ 模块化清晰
- ✅ 逐步验证
- ✅ 易于调试和理解

## 💡 核心发现

### 1. 精度 vs 性能的权衡

**DeepSeek的选择**:
```python
# 明确注释: fp32精确, 不用TF32
```

| 方案 | 性能 | 精度 | 适用场景 |
|------|------|------|---------|
| **TF32** (Codex) | 最快 ⚡ | 高精度 | 生产环境 |
| **FP32** (DeepSeek) | 较慢 | **最高精度** ⚡ | 科研/验证 |
| **FP16** (Gemini/Claude) | 中等 | 中等精度 | 平衡方案 |

**性能差距分析**:
- FP32 vs TF32: 约15-20%性能差距
- DeepSeek: 6.10秒
- 如果使用TF32: 估计5.0-5.5秒
- 与Codex-sol-2差距: 2.0-2.5秒

### 2. 独立子进程架构的价值

**问题**: fork + CUDA死锁
**解决方案对比**:

| 方案 | 实现 | 优点 | 缺点 |
|------|------|------|------|
| **Fork共享内存** (Codex) | 父进程加载，子进程共享 | 最快 ⚡ | 可能死锁 |
| **独立子进程** (DeepSeek) ⚡ | 子进程独立加载 | 稳定 ✅ | 启动慢 |
| **标准多进程** (其他) | 标准库 | 简单 | 一般 |

**DeepSeek优势**:
- ✅ 完全避免CUDA fork问题
- ✅ 主进程不导入torch
- ✅ 结果通过文件交换，解耦彻底
- ⚠️ 约5秒固定启动开销

### 3. 数值验证的重要性

**DeepSeek的验证策略** ⚡:
1. **CPU float64基准**: 前2000样本，完整计算对照
