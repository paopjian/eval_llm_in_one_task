## 详细失败分析

### 1. GLM-Pro & DeepSeek-Pro - 系统内存泄漏

**现象**:
```
GPU状态（正常）：7卡 99-100%利用率，7.7GB显存/卡
系统内存（异常）：0s:10GB → 30s:28GB → 60s:158GB
```

**结论**: 代码设计缺陷，计算过程中系统内存持续泄漏，无法完成评估

---

### 2. Codex-Sol-M - 并行失败

**现象**:
```
- 7个GPU进程都启动（各占8GB显存）
- 但只有1个进程CPU 100%在工作
- 其余6个进程处于睡眠状态
- GPU利用率0-9%
```

**结论**: multiprocessing实现有问题，比不上同系列的Codex-Sol和Codex-Sol-2

---

### 3. Claude-Opus - 临时文件管理问题

**错误**:
```
FileNotFoundError: [Errno 2] No such file or directory: '/tmp/tmpjsalrq9h/gpu_0.pkl'
```

**现象**: 运行960秒后失败，多GPU计算时临时文件管理有问题

**结论**: 代码在临时文件创建或路径管理上有缺陷

---

### 4. DeepSeek - 直方图计数不一致

**错误**:
```
AssertionError: 直方图计数不一致!
```

**现象**: 启动9秒后立即失败

**结论**: 数据验证逻辑有bug，或与200万数据规模不兼容
