# 大规模人脸特征相似度评估总结报告

## 1. 任务范围

本次任务在当前任务目录内完成了人脸特征相似度评估程序，实现以下功能：

- 读取 `s4_0618_enhance.pkl` 特征文件并校验数据结构；
- 计算上三角样本对的余弦相似度；
- 区分正样本对和负样本对；
- 计算 TPIR@FPIR 指标并绘制曲线；
- 绘制正负样本相似度分布图；
- 按阈值提取潜在误接受和误拒绝样本对；
- 使用多 GPU 并行处理大规模样本对。

## 2. 数据概况

| 项目 | 数值 |
| --- | ---: |
| 样本数 | 203,234 |
| 特征维度 | 512 |

特征已经完成 L2 归一化，因此相似度使用特征矩阵乘法直接计算。

## 3. 实现方案

程序文件为 `face_similarity_evaluator.py`，核心设计如下：

1. 只生成上三角分块任务，避免重复计算和对角线样本。
2. 默认块大小为 8,192，控制单块显存和临时矩阵大小。
3. 预先建立稀疏正样本坐标索引，负样本直方图由全部样本直方图减去正样本直方图得到。
4. 使用 200,000 个直方图桶统计 `[-1, 1]` 相似度，分辨率为 `1e-5`，避免保存约 206 亿个相似度值。
5. 使用 `int64` 直方图计数，避免大规模计数的浮点精度问题。
6. 自动发现最多 7 张 CUDA GPU，并通过 Linux `fork` 启动独立 GPU worker。
7. GPU 不可用或显式指定 CPU 时直接报错，程序不会回退到 CPU。
8. 表格结果使用 Parquet 格式保存，未安装新依赖。

## 4. GPU 执行结果

宿主机检测到 7 张 NVIDIA GeForce RTX 4090，程序自动使用：

```text
cuda:0, cuda:1, cuda:2, cuda:3, cuda:4, cuda:5, cuda:6
```

全量评估成功完成，计算阶段耗时约 2.96 秒。所有分块任务合计的样本对数量与理论值一致，正负样本统计校验均通过。

## 6. 错误样本提取

使用以下参数完成了端到端验证：

```bash
conda run -n cvlface python "face_similarity_evaluator.py" \
  --no-plots \
  --extract-above 0.5 \
  --extract-below 0.3 \
  --max-extracted 20
```

生成 40 条错误样本记录：

- `negative_above`：20 条，负样本相似度不低于 0.5；
- `positive_below`：20 条，正样本相似度不高于 0.3。
