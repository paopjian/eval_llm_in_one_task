# 全模型性能测试说明

## 📋 测试目标

对所有12个LLM模型生成的代码进行统一基准测试，使用相同的测试数据集，公平对比性能差异。

## 🎯 为什么要测试所有模型？

之前的unified_benchmark.py只测试了**5个最优方法**：
- hybrid_optimal
- grok_threadpool  
- codex_tf32
- deepseek_precise
- glm_highres

但实际上有**12个LLM模型**参与了项目，每个模型都生成了完整的可执行代码。我们需要测试所有模型的代码，才能：

1. **完整评估**: 看到所有12个模型的真实性能表现
2. **发现差异**: 了解为什么某些方法被选为"最优"
3. **公平对比**: 在统一环境（相同硬件、相同数据）下测试
4. **架构分析**: 分析不同架构选择对性能的影响

### 测试指标
1. **总耗时**: 从开始到结束的总时间

4. **吞吐率**: 样本对数/秒
5. **内存使用**: 峰值内存占用
6. **正确性**: TPIR@FPIR指标验证
