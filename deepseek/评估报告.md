## 2. 实现方法（内存与 N 无关）

1. 特征已归一化 → 相似度 = 分块上三角矩阵乘法（block=8192），不保存全量 N×N 矩阵；
2. 每块相似度实时量化为 20 万 bin 直方图（bin 宽 1e-5），累计正/负样本相似度直方图 → 内存恒定 O(bins)；
3. 对角线块利用 `S=A@A^T` 精确对称性（自检确认逐位对称），2 次 bincount 即完成上三角去重；
4. **多卡并行**：行块按 GPU 数轮询分配（上三角三角工作区天然负载均衡），每张卡跑独立子进程（`gpu_worker.py`，避免 fork+CUDA 死锁），最后 CPU 合并直方图；
5. 阈值样本对提取：二次遍历（只算相似度不做直方图）+ 流式 top-K 裁剪，above/below 两方向。

## 4. TPIR@FPIR 评估结果（7 卡，nbins=200000，bin宽=1e-5）

| FPIR | 阈值（相似度） | TPIR | 文档期望区间 | 判定 |
|---|---|---|---|---|
| 1e-5 | 0.493720 | **63.95%** | 60~65% | ✓ OK |
| 1e-4 | 0.386491 | **83.85%** | 82~85% | ✓ OK |
| 1e-3 | 0.313255 | **91.91%** | 90~93% | ✓ OK |
| 1e-2 | 0.233235 | **96.67%** | 95~97% | ✓ OK |

> 说明：阈值为「负样本相似度 > t 的比例 = FPIR」的反解（bin 内线性插值，精度优于 1e-5），TPIR 为该阈值下正样本通过率。四个评估点全部落在文档预期区间内。

## 5. 运行耗时明细

### 5.1 相似度统计阶段（核心计算）

| 模式 | GPU 纯计算 | 每卡进程墙钟 | 总墙钟（含启动/载入） |
|---|---|---|---|
| 单卡（GPU0） | 2.48 s | 2.48 s | **5.68 s** |
| 7 卡并行 | 0.50~0.69 s/卡（合计 4.24 s） | 0.51~0.69 s | **6.10 s**（run_eval 复测 6.22 s） |

- 7 卡 GPU 纯计算加速比 ≈ **4.0×**（2.48 s → 0.62 s/卡并行）；
- 总墙钟差异小的原因：约 5 s 为固定开销——7 个子进程并行启动 + import torch + 读取 pkl（数据量越大多卡优势越明显）；
- 各阶段实测：数据载入 ~0.3 s，自检 ~3.6 s，绘图 ~1.4 s。

### 5.2 完整流程（run_eval.py 一键运行）

| 阶段 | 耗时 |
|---|---|
| 数据载入 | 0.3 s |
| 7 卡直方图统计 | 6.1 s（GPU 纯算每卡 ~0.6 s） |
| TPIR@FPIR 指标计算 | <0.1 s |
| 出图（分布图 + 曲线图） | ~1.4 s |
| **→ 指标+图表全部就绪** | **≈ 10~12 s** |
| 样本对提取二次遍历（above+below，7 卡） | 27~30 s |
| **→ 一键全流程总耗时（含提取）** | **41.5 s** |

## 8. 复现方法

```bash
export LD_LIBRARY_PATH=$CONDA_PREFIX/lib
PY=python

$PY step1_analyze_data.py                      # 数据分析
$PY step2_single_gpu.py                        # 单卡评估(含CPU float64自检)
$PY step3_multi_gpu.py                         # 7卡并行评估
$PY step4_extract_pairs.py --fpir 1e-3         # 样本对提取
$PY step5_plot_results.py --tag multi          # 可视化
$PY run_eval.py --extract-fpir 1e-3            # 一键全流程(~12s出图, 41.5s含提取)
```

主要代码：`faireval_lib.py`（核心库）、`gpu_worker.py`（GPU 子进程）、`run_eval.py`（一键入口）。
