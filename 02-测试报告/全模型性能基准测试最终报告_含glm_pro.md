## 💡 关键教训

### 1. 字体路径使用绝对路径
3个模型因相对路径失败，修复后都能运行：
```python
# ❌ 错误
FONT_PATH = 'font/SourceHanSansSC-Normal.otf'

# ✅ 正确
FONT_PATH = '/root/zhaokj/font/SourceHanSansSC-Normal.otf'
```

### 2. 简单不一定慢
- qwen使用单GPU实现，代码最简洁
- 但性能最好（6.05秒，第1名）
- 说明算法效率比多卡并行更重要

### 3. pro版本确实更强
- GLM-5.3-pro比flash快60.4%
- DeepSeek v4-pro比flash快46.6%
- 升级到pro版本有显著性能提升

### 4. 开发时间与性能无关
- qwen: 快速开发 → 最好性能
- claude-opus: 231.3分钟 → 最差性能
- 关键在于算法选择，不是开发时长
