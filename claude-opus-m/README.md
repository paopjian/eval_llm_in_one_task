# 人脸特征相似度评估系统

## 项目概述

本项目实现了一个高效的大规模人脸特征相似度矩阵计算与评估系统，能够处理20万+样本、206亿样本对的相似度计算，支持多GPU并行加速。

## 核心功能

### ✅ 已实现功能

1. **数据加载与分析**
   - 读取pkl格式的特征文件
   - 统计样本数量、身份数量、正负样本对数量
   - 验证特征归一化状态

2. **高效相似度计算**
   - 多GPU并行计算（支持7卡并行）
   - 分块矩阵运算避免OOM
   - 只计算上三角矩阵避免重复计算
   - 使用直方图统计避免存储所有相似度值

3. **TPIR@FPIR指标计算**
   - 计算特定FPIR点的TPIR值
   - 生成完整的TPIR@FPIR曲线
   - 支持自定义FPIR阈值

4. **可视化**
   - 正负样本相似度分布图
   - TPIR@FPIR曲线图
   - 标注关键评估点

## 技术特点

### 1. 内存优化
- **直方图统计**: 不存储所有206亿个相似度值，使用10000个bins的直方图统计
- **分块计算**: 避免一次性加载整个相似度矩阵

### 2. 计算优化
- **上三角计算**: 只计算矩阵的上三角部分，节省50%计算量
- **向量化操作**: 充分利用GPU矩阵运算
- **批量处理**: 大块矩阵乘法提高GPU利用率

### 3. 多GPU并行
- **负载均衡**: 按行均匀分配任务给7个GPU
- **独立计算**: 每个GPU独立计算自己的行范围
- **结果合并**: 最后合并所有GPU的直方图结果

### 4. 正确性保证
- **上三角逻辑**: 
  - 每个GPU处理行范围[row_start, row_end)
  - 对于每一行i，计算与所有j > i的相似度
  - 分两部分：块内上三角 + 块外所有列
- **样本对验证**: 最终统计的样本对数量与理论值完全匹配

## 关键算法

### 上三角矩阵计算

对于NxN的相似度矩阵，只需要计算上三角部分（i < j）：

```
GPU 0 处理行 [0, 29033):
  对于每一行 i:
    1. 块内上三角: 计算 i 与 [i+1, 29033) 的相似度
    2. 块外全部: 计算 i 与 [29033, N) 的相似度

GPU 1 处理行 [29033, 58066):
  对于每一行 i:
    1. 块内上三角: 计算 i 与 [i+1, 58066) 的相似度
    2. 块外全部: 计算 i 与 [58066, N) 的相似度

...以此类推
```

这样确保：
- 每个样本对 (i, j) 其中 i < j 只被计算一次
- 没有重复计算
- 没有遗漏计算

### 直方图统计

```python
# 使用10000个bins统计相似度分布
bins = np.linspace(-1, 1, 10001)  # 10001个边界，10000个bins
pos_hist = np.zeros(10000)  # 正样本直方图
neg_hist = np.zeros(10000)  # 负样本直方图

# 对每个相似度值
sim_val = 0.5  # 例如
bin_idx = int((sim_val + 1) / 2 * 10000)  # 映射到bin索引
if is_positive:
    pos_hist[bin_idx] += 1
else:
    neg_hist[bin_idx] += 1
```

这样只需要存储20000个数值，而不是206亿个相似度值。

### TPIR@FPIR计算

```python
# 从直方图计算累积分布
neg_cumsum = np.cumsum(neg_hist[::-1])[::-1]  # 相似度>=阈值的负样本数
pos_cumsum = np.cumsum(pos_hist[::-1])[::-1]  # 相似度>=阈值的正样本数

# 对于给定的FPIR
fpir = 1e-4
target_neg_count = int(fpir * total_neg)  # 允许的最大假阳性数

# 找到对应的阈值
idx = np.searchsorted(neg_cumsum[::-1], target_neg_count)
threshold = bins[idx]

# 计算该阈值下的TPIR
tpir = pos_cumsum[idx] / total_pos
```
