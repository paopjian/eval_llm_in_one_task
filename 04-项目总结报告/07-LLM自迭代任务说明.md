# LLM自迭代任务：大规模人脸特征相似度矩阵计算与评估

## 任务背景

本任务旨在测试LLM的自我迭代能力，从最基础的特征读取和单卡NxN相似度计算开始，逐步演进到能够高效处理大规模数据的多卡并行评估系统，最终实现TPIR@FPIR指标计算和可视化。

## 环境说明

- **Python环境**: `/root/miniconda3/envs/cvlface`（已激活）
- **可用显卡**: 7张GPU（cuda:0 到 cuda:6）
- **库限制**: 禁止安装任何新库，只能使用环境中已有的库
- **数据路径**: `s4_0618_enhance.pkl`


## 任务目标

**最终目标**：启动代码后以最快速度获取TPIR@FPIR曲线和相似度分布图。

**核心功能要求**：
1. 读取特征文件并理解数据结构
2. 计算NxN相似度矩阵，区分正负样本
3. 计算TPIR@FPIR指标（见下方说明）
4. 支持提取above/below阈值的样本对（用于错误分析）
5. 绘制评估图表（相似度分布图、TPIR@FPIR曲线）
6. 支持多卡并行加速

**性能要求**：
- 能够处理大规模数据（样本数可能达到数万，样本对数达到亿级）
- 计算速度尽可能快
- 内存占用合理

**1.3 TPIR@FPIR计算**

   - 过高精度可能带来不必要的计算和存储开销

## 评估指标说明

### 正负样本定义
- **正样本对**：`query_ids[i] == query_ids[j]` 且 `i < j`
- **负样本对**：`query_ids[i] != query_ids[j]` 且 `i < j`

### TPIR@FPIR计算
```
给定阈值 threshold:
FPIR(threshold) = (负样本中 sim > threshold 的数量) / (总负样本数)
TPIR(threshold) = (正样本中 sim > threshold 的数量) / (总正样本数)

常见评估点：
- TPIR @ FPIR=1e-3
- TPIR @ FPIR=1e-4  
- TPIR @ FPIR=1e-5
```
