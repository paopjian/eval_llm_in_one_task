## 🔧 测试数据生成系统特点

### 预设配置

| 预设 | 样本数 | 样本对数 | 生成时间 | 适用场景 |
|------|-------|---------|---------|---------|
| quick | 2,500 | 3.1M | ~1秒 | 快速验证 |
| medium | 20,000 | 200M | ~10秒 | 开发测试 |
| large | 75,000 | 2.8B | ~1分钟 | 性能测试 |
| xlarge | 200,000 | 20B | ~10分钟 | 超大规模 |
| realistic | 200,000 | 20B | ~10分钟 | 真实场景 |

### 可调参数

- **num_identities**: 身份数量
- **samples_per_identity**: 每身份样本数
- **noise_std**: 难度控制 (0.10理想 ~ 0.30困难)
- **seed**: 随机种子（确保可复现）
- **feat_dim**: 特征维度（默认512）

### 使用方式

```bash
# 快速测试
python generate_test_data.py --preset quick

# 自定义配置
python generate_test_data.py \
    --num_identities 5000 \
    --samples_per_identity 20 \
    --noise_std 0.15 \
    --seed 42

# 验证数据
python validate_test_data.py test_data.pkl

# 运行示例
python example_usage.py
```
