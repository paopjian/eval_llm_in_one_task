# 总结文档：大规模人脸特征相似度矩阵计算与评估

## 1. 任务概述

读取 `s4_0618_enhance.pkl` 人脸特征文件，计算 NxN 上三角相似度矩阵（**206 亿样本对**），
区分正负样本，计算 TPIR@FPIR 指标，支持 above/below 阈值样本对提取，绘制评估图表，
并利用 7 张 RTX 4090 多卡并行将端到端耗时压缩到最短。

环境：`cvlface`（torch 2.12.0+cu126 / numpy 2.2.6 / matplotlib 3.10.9），
7× RTX 4090 24GB，未安装任何新库。

## 2. 数据规模

| 项目 | 数值 |
|---|---|
| 样本数 N | 203,234（512 维，L2 归一化，范数均值 1.000000） |
| 身份数 | 9,940（每身份 11~38 张，均值 20.45） |
| 总样本对 | 20,651,927,761（206.5 亿） |
| 正样本对 | 2,179,084（0.0106%） |
| 负样本对 | 20,649,748,677（99.9894%） |

## 3. 迭代演进过程

### v0 — 数据分析（`test_load_data.py`）
读取 pkl、统计正负样本对、校验归一化。耗时 0.8s。

### v1 — 单卡基础版（`eval_v1_single_gpu.py`）
单 GPU 分块（每块约 1e8 元素）计算全行相似度，掩码取上三角，
用 **2M-bin 直方图**（bin 宽 1e-6）在 GPU 上 `bincount` 累积正/负样本相似度分布，
替代全量相似度保存（206 亿 float32 = 82GB，不可行；直方图仅 32MB）。
从直方图右端累积得到 TPIR@FPIR。单卡计算 6.69s，端到端 8.63s。
**一次运行即验证指标全部落在预期范围内**，作为正确性基线。

### v2 — 多卡并行最终版（`eval_v2_multi_gpu.py`）
在 v1 基础上的四项关键优化 + 样本对提取功能：

1. **负载均衡划分**：行 i 的有效工作量为 (N-1-i)，按前缀和
   `W(r)=r(N-1)-r(r-1)/2` 二分求解切分点，使各卡**样本对数**严格相等
   （实测各卡 29.50 亿 ± 0.002%）。
2. **对角块列跳过**：行块 `[s,e)` 只与列 `[s+1,N)` 做矩阵乘，总计算量减半；
   同时使"各卡元素数 == 各卡样本对数"，负载均衡真正生效。
   优化前各卡 kernel 耗时 1.15~3.51s（尾卡空算 80%），优化后 0.82~1.36s 均匀。
   块高按剩余列数自适应（`1e8/(N-s)`），尾部行块自动加高保持 GPU 利用率。
3. **fork 启动方式**（`--mp-method fork`）：父进程不触碰 CUDA，fork 子进程
   免去重复 import torch（spawn 需每子进程 ~2-3s），启动开销从 ~6s 降到 ~2s。
4. **样本对分类配额提取**：true_accept / false_accept / false_reject / true_reject
   四类各自独立配额，错误分析最关心的 false_accept、false_reject 不被数量占优的
   类别挤掉；count 全量统计、明细超限截断并显式标记；输出 NPZ（全量明细）+ CSV（限行数、含图片路径）。

### 过程中遇到的问题与解决

| 问题 | 现象 | 解决 |
|---|---|---|
| matplotlib 导入失败 | `CXXABI_1.3.15 not found`（系统 libstdc++ 过旧） | 运行时加 `LD_LIBRARY_PATH=$CONDA_PREFIX/lib` |
| 多卡结果回传崩溃 | torch 张量经 `mp.Queue` 走 fd 共享存储还原，worker 先退出导致主进程 `EOFError` | worker 内一律 `.numpy()` 后入队（numpy 按原始字节 pickle） |
| 尾卡负载不均 | 按行均分时尾卡空算严重（3.51s vs 1.15s） | 对角块列跳过 + 按样本对数均衡划分 |
| 提取配额被挤占 | 正负样本共享配额时 true_accept 占满单卡配额 | 四类独立配额 |

## 5. 性能总结

| 配置 | 计算墙钟 | 端到端总耗时 | 吞吐（样本对/秒） |
|---|---|---|---|
| v1 单卡（无提取） | 6.69s | 8.63s | 30.9 亿 |
| v2 7卡 spawn + 提取 | 4.07~8.66s | 14.98~19.5s | 24~51 亿 |
| **v2 7卡 fork（无提取，最快出图）** | **3.21s** | **5.25s** | **64.3 亿** |
| v2 7卡 fork + 提取 | 4.07s | 14.98s（含 CSV/NPZ 写盘 9.0s） | 50.7 亿 |

- 206 亿样本对：单卡 kernel 6.69s → 7 卡 kernel 0.82~1.00s（无提取），
  端到端（读盘→计算→指标→两张图）**5.25 秒**。
- 内存：每卡峰值显存约 3GB（分块 ~1e8 元素）；CPU 侧仅直方图 32MB + 特征 416MB 共享内存。
- 直方图已存盘（`results/v2_hist_*.npy`），复算指标/换阈值出图无需重跑 GPU。

## 7. 复现命令

```bash
cd qwen
export LD_LIBRARY_PATH=$CONDA_PREFIX/lib

# 最快速度出图（5.25s）
python eval_v2_multi_gpu.py \
    --gpus 0,1,2,3,4,5,6 --mp-method fork

# 完整功能（含阈值0.4样本对提取，约15s）
python eval_v2_multi_gpu.py \
    --gpus 0,1,2,3,4,5,6 --mp-method fork \
    --extract-threshold 0.4 --extract-mode both --max-extract 2000000

# 单卡基线对照
python eval_v1_single_gpu.py --gpu 0
```

主要参数：`--gpus` 卡列表、`--nbins` 直方图精度、`--extract-threshold/--extract-mode
(above|below|both)`、`--max-extract` 每类明细上限、`--max-csv-rows` CSV 行数、
`--mp-method spawn|fork`、`--outdir`。
